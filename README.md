# Space Wiki 정적 데모

개인정보와 실제 업무 데이터를 포함하지 않는 3D Wiki 화면 시연 패키지입니다. 프로젝트, 문서, 연결 관계와 본문은 모두 모크 데이터이며 외부 API, 계정 인증, AI 작업실, ERP 기능을 사용하지 않습니다.

## 실행

Node.js가 설치된 환경에서 이 폴더를 열고 다음 명령을 실행합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 포트를 바꾸려면 실행 전에 `PORT` 환경 변수를 지정합니다.

정적 웹 호스팅에도 폴더 구조를 그대로 업로드할 수 있습니다. ES Module과 import map을 사용하므로 `index.html`을 직접 더블클릭하지 말고 HTTP(S) 주소로 실행해야 합니다.

## 포함 범위

- 3D 행성·문서 시각화
- 카메라 이동, 둘러보기, 필터, 전체화면과 표시 설정
- 시연용 프로젝트 14개와 문서 점 1,800개
- 읽을 수 있는 모크 문서 42개
- 로컬 포함 Three.js와 OrbitControls

## 제외 범위

- 실제 사용자·회사·고객·계정 데이터
- AI 작업실, ERP, OAuth와 외부 서비스 연결
- 서버 저장, 데이터베이스와 브라우저 저장소 사용
- 로그, 환경 변수 파일, 인증 정보와 실제 업무 파일
